Movers App

Overview
The Movers App is a comprehensive web application designed to facilitate the moving process for both movers and customers. The app allows users to get quotes, book moving services, manage inventory, and more.

Features
User Authentication: Secure login and registration for customers and movers.
Quotes: Get instant quotes based on moving details.
Booking: Schedule and manage moving appointments.
Inventory Management: Track and manage inventory for moving services.
Dashboard: View and manage bookings, quotes, and inventory.

Technologies
Front-End: React 
Back-End: Flask (Python) 
Database: PostgreSQL / MySQL 
Authentication: JWT (JSON Web Tokens)
